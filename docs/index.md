# YubaLANG documentation

## Beginner path

1. [Install or update YubaLANG](install.md).
2. Work through [Getting started](getting-started.md) and run its example.
3. Try the interactive interpreter with `YubaLANG repl`.
4. Browse the [complete example catalog](examples.md).

## Advanced interoperability

- [Calling native C functions](c-abi.md).

Standalone release executables are available for Windows x64, Linux x64,
macOS Intel, and macOS Apple Silicon. They bundle Python. Running from source
requires Python 3.10 or newer; Git is required only for Git dependencies.
See the [installation guide](install.md) for platform targets, installation,
and build details.
