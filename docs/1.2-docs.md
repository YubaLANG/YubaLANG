# YubaLANG 1.2

YubaLANG is an interpreted language whose programs use readable, grouped
commands. This reference describes the language and built-ins available in
version 1.2.

## Running a program

Save a program with the `.yl` extension and run it from the repository root:

```text
py YubaLANG.py path\to\program.yl
```

For example:

```text
py YubaLANG.py hello.yl
```

## Comments

Start a comment with `#`. Text after `#` on a command line is ignored.

```hl
# A full-line comment
text output "Hello!" # An inline comment
```

## Variables and types

Declare a variable with:

```hl
define var <name>: <type> = <value>
```

The supported types are `int`, `float`, `string`, `bool`, `list`, `dict`,
`set`, `tuple`, `bytes`, and `bytearray`. `file` and `iterator` values are
created by `open` and `iter`, respectively.

```hl
define var attempts: int = 3
define var ratio: float = 0.75
define var greeting: string = "Hello, YubaLANG!"
define var enabled: bool = true
define var numbers: list = [10, 20, 30]
define var settings: dict = {"language": "YubaLANG", "year": 2026}
define var colors: set = {"red", "green", "blue"}
define var point: tuple = (4, 9)
define var payload: bytes = "hello"
define var buffer: bytearray = "hello"
```

Strings may use single or double quotes and support common escapes such as
`\\n`, `\\t`, `\\\\`, `\\"`, and `\\'`. Double backslashes when writing literal
backslashes, including Windows paths. Booleans are written `true` or `false`.
Collection literals can include values and references to variables:

```hl
define var first: int = 10
define var second: int = first
define var values: list = [first, 20, "thirty"]
```

## Text input and output

Print values with `text output`:

```hl
text output "Hello, world!"
text output first
```

Read a line into an existing string variable with `text input`:

```hl
define var name: string = ""
text output "What is your name?"
text input name
text output name
```

## Type conversion

`convert` changes the type and value of an existing variable. Both forms are
supported:

```hl
convert <variable> to <type>
convert <variable> <type>
```

For example:

```hl
define var count: int = 42
convert count to float
text output count
```

Conversion targets are `int`, `float`, `string`, `bool`, `list`, `dict`,
`set`, `tuple`, `bytes`, and `bytearray`. A conversion that cannot be performed
reports a runtime error.

## Arithmetic

Arithmetic expressions use `arith`; each command prints its result:

```hl
arith add 10 5
arith sub 10 5
arith mul 10 5
arith div 10 5
arith mod 10 3
arith pow 2 8
arith divmod 17 5
```

Single-argument operations are `abs`, `round`, `bin`, `hex`, and `oct`:

```hl
arith abs -12
arith round 3.75
arith bin 10
arith hex 255
arith oct 64
```

`sum`, `max`, and `min` accept a list, tuple, or set. `max` and `min` also
accept two numeric operands:

```hl
define var measurements: list = [4, 8, 2]
arith sum measurements
arith max measurements
arith min measurements
arith max 8 2
```

Division and modulo by zero produce errors.

## Comparisons

Compare two values and store the result in an existing boolean variable:

```hl
compare <value1> <operator> <value2> <bool_variable>
```

Supported operators: `==`, `!=`, `<`, `>`, `<=`, and `>=`.

```hl
define var score: int = 85
define var passed: bool = false
compare score >= 60 passed
text output passed
```

## Conditional blocks

Use `if`, optional `elseif` branches, optional `else`, and `endif`:

```hl
define var score: int = 85
define var passed: bool = false
compare score >= 60 passed

if passed
    text output "Passed"
else
    text output "Try again"
endif
```

Conditions can be boolean literals or boolean variables.

## Functions

Functions can be defined with zero or more positional parameters:

```hl
func define greet name
    text output name
endfunc

func call greet "Hello!"
```

Each function call has a local scope. A local variable with the same name as a
global variable does not overwrite the global variable.

`return` exits the current function. To return a value, follow it with a value
or variable. A call may store that result in an existing destination variable
using `->`:

```hl
func define identity value
    return value
endfunc

define var answer: int = 0
func call identity 42 -> answer
text output answer
```

Calls must provide the number of arguments declared by the function.

## Imports

Import a local module or a package dependency with an optional namespace
alias:

```hl
import helpers
import local_math as math

define var answer: int = 0
func call math.add 20 22 -> answer
```

Local imports resolve beside the importing file as `<name>.yl` or
`<name>/main.yl`. Dotted module names follow directories. A declared package
dependency resolves to its manifest entry file. Imported functions are
namespaced and called with `func call namespace.function`; functions within a
module can call their own helpers by their unqualified name. Modules are
executed once per run, and cycles are errors. Top-level module commands run on
first import, while module variables share the runtime's global scope.

See the [project and package guide](package-manager.md) for manifest, lockfile,
and dependency commands.

## Loops and control flow

Repeat a block a fixed number of times:

```hl
loop for 3
    text output "Once per iteration"
endloop
```

The count may be an integer variable. Repeat while a boolean condition is
true:

```hl
define var running: bool = true
loop while running
    text output "Running"
    define var running: bool = false
endloop
```

`break` exits the current loop; `continue` skips to its next iteration.
`return` exits the current function.

## Collections

Lists, dictionaries, sets, and tuples can be declared with literals.

List commands:

```hl
list append <list> <value>
list get <list> <index> <destination>
list len <list> <int_destination>
```

Indices start at zero. For example:

```hl
define var numbers: list = [10, 20, 30]
define var item: int = 0
list get numbers 1 item
list append numbers 40
```

Dictionary commands:

```hl
dict set <dictionary> <key> <value>
dict get <dictionary> <key> <destination>
```

Set commands:

```hl
set add <set> <value>
set remove <set> <value>
```

Tuple values are read by index:

```hl
tuple get <tuple> <index> <destination>
```

`all` and `any` test the truthiness of collection members. `len` returns a
collection or string's length:

```hl
define var values: list = [1, 2, 3]
define var every_value: bool = false
define var item_count: int = 0
all values every_value
len values item_count
```

## Character, string, and iteration built-ins

The character and string commands include `ascii`, `chr`, `ord`, `format`, and
`repr`. Iteration commands include `enumerate`, `filter`, `iter`, `map`,
`next`, `range`, `reversed`, `slice`, `sorted`, and `zip`.

Their exact command forms, destination requirements, examples, and behavior
are documented in the [built-in function reference](builtins.md).
Runnable 1.2 programs are available in the [examples directory](../examples/).

`map` and `filter` accept either a supported unary built-in function or a
user-defined one-parameter function that returns a value.

## Other built-ins

* `bool <value> <bool_destination>` converts a value to a boolean.
* `callable <function_name> <bool_destination>` checks for a known built-in or
  user-defined function.
* `id <variable> <int_destination>` reports the identity of a variable's
  current value.
* `type <variable> <string_destination>` stores its YubaLANG type name.
* `vars` prints active variables and defined functions.
* `bytes <value> <destination>` and `bytearray <value> <destination>` create
  byte sequences.
* `getattr <variable> <attribute_or_key> <destination>`,
  `hasattr <variable> <attribute_or_key> <bool_destination>`, and
  `setattr <variable> <attribute_or_key> <value>` inspect or update object
  attributes and dictionary keys.
* `open <path> <mode> <file_destination>` opens a file using UTF-8 text
  encoding (binary modes are also accepted). For a Windows path, escape
  backslashes, for example `open "C:\\\\data\\\\notes.txt" "r" handle`.
* `wait <seconds>` pauses execution for the specified duration.

Most built-ins that write a result require a destination variable with the
appropriate type already declared. `iter` creates an iterator variable when
the destination name does not exist yet.

## Errors

Invalid syntax, unknown commands, undefined variables, invalid conversions,
type mismatches, invalid collection indices, and arithmetic errors are
reported with the source file, line and column, the relevant source line, and
a caret marking the location. When a likely correction is known, YubaLANG
suggests it:

```text
program.yl:4:13: error: Variable 'coutn' is not defined.
  line 4: text output coutn
                        ^^^^^
  hint: Did you mean 'count'?
```

Errors inside functions and control-flow blocks retain their original source
locations. These diagnostics describe interpreted source errors and omit
internal Python stack traces.

Commands with incorrect arguments report their expected usage.

## Complete example

```hl
define var numbers: list = [-2, 0, 5, 8]
define var positives: list = []
define var largest: int = 0

func define is_positive value
    define var result: bool = false
    compare value > 0 result
    return result
endfunc

filter is_positive numbers positives
sorted positives positives
list get positives 1 largest

text output "Positive values:"
text output positives
text output "Second positive value:"
text output largest

loop for 2
    text output "Done"
endloop
```
