# YubaLANG 1.0.0

YubaLANG is a simple interpreted programming language designed around clear, grouped commands.

See the [built-in function reference](builtins.md) for available built-ins,
iteration commands, and user-defined function arguments and return values.

## Running YubaLANG

Run a YubaLANG source file with:

```text
py YubaLANG.py <path_to_file.hl>
```

For example:

```text
py YubaLANG.py hello.hl
```

YubaLANG programs use the `.hl` file extension.

---

# 1. Comments

Comments begin with `#`.

```hl
# This is a comment
text output "Hello!"
```

Comments can also appear after commands:

```hl
text output "Hello!" # This prints Hello!
```

---

# 2. Variables

Variables are declared with:

```hl
define var <name>: <type> = <value>
```

YubaLANG currently supports these types:

* `int`
* `float`
* `string`
* `bool`
* `list`

## Integers

```hl
define var age: int = 15
```

## Floating-point numbers

```hl
define var pi: float = 3.14
```

## Strings

Strings can use either double or single quotes.

```hl
define var name: string = "YubaLANG"
define var other: string = 'Hello'
```

## Booleans

Boolean values are:

```hl
true
false
```

Example:

```hl
define var enabled: bool = true
```

## Lists

Lists are written using square brackets.

```hl
define var numbers: list = [1, 2, 3, 4, 5]
```

Lists can contain strings as well:

```hl
define var names: list = ["Alex", "Sam", "Jordan"]
```

Variables can be used as values when defining another variable:

```hl
define var first: int = 10
define var second: int = first
```

---

# 3. Type Conversion

The `convert` command changes the type of an existing variable.

Syntax:

```hl
convert <variable> to <type>
```

It can also be written without `to`:

```hl
convert <variable> <type>
```

Example:

```hl
define var number: int = 42

convert number to float

text output number
```

Supported conversions include:

* `int`
* `float`
* `string`
* `bool`
* `list`

For example:

```hl
define var number: int = 42
convert number to string
text output number
```

---

# 4. Text Output

Use:

```hl
text output <value>
```

Strings can be printed directly:

```hl
text output "Hello, world!"
```

Variables can also be printed:

```hl
define var message: string = "Hello!"
text output message
```

---

# 5. Text Input

Use:

```hl
text input <variable>
```

The destination variable must already exist and must be a `string`.

Example:

```hl
define var name: string = ""

text output "What is your name?"
text input name

text output name
```

# 6. Arithmetic

Arithmetic commands use:

```hl
arith <operation> <value>
```

or:

```hl
arith <operation> <value1> <value2>
```

## Addition

```hl
arith add 5 3
```

Output:

```text
8
```

## Subtraction

```hl
arith sub 5 3
```

## Multiplication

```hl
arith mul 5 3
```

## Division

```hl
arith div 10 2
```

## Modulo

```hl
arith mod 10 3
```

## Absolute value

```hl
arith abs -10
```

## Rounding

```hl
arith round 3.7
```

## Maximum

```hl
arith max 10 20
```

## Minimum

```hl
arith min 10 20
```

## List sum

`sum` can be used with a list:

```hl
define var numbers: list = [1, 2, 3, 4]

arith sum numbers
```

This outputs:

```text
10
```

`max` and `min` can also operate on lists:

```hl
define var numbers: list = [4, 8, 2, 9]

arith max numbers
arith min numbers
```

---

# 7. Comparisons

Comparisons use:

```hl
compare <value1> <operator> <value2> <destination>
```

The destination must already be a `bool` variable.

Supported operators:

```text
==
!=
<
>
<=
>=
```

Example:

```hl
define var result: bool = false

compare 10 > 5 result

text output result
```

The result becomes `true`.

Variables can also be compared:

```hl
define var a: int = 10
define var b: int = 20
define var result: bool = false

compare a < b result
```

---

# 8. If Statements

Conditional blocks use:

```hl
if <condition>
    ...
endif
```

Example:

```hl
define var enabled: bool = true

if enabled
    text output "Enabled!"
endif
```

YubaLANG also supports `elseif` and `else`.

```hl
define var number: int = 10
define var positive: bool = false
define var negative: bool = false

compare number > 0 positive
compare number < 0 negative

if positive
    text output "Positive"
elseif negative
    text output "Negative"
else
    text output "Zero"
endif
```

---

# 9. Functions

Functions are defined with:

```hl
func define <function_name>
    ...
endfunc
```

They are called with:

```hl
func call <function_name>
```

Example:

```hl
func define hello
    text output "Hello from a function!"
endfunc

func call hello
```

Functions have their own local scope when called.

---

# 10. Return

`return` exits the currently running function.

Example:

```hl
func define stop
    text output "Before return"
    return
    text output "This will not run"
endfunc

func call stop
```

The command after `return` is not executed.

---

# 11. For Loops

A `for` loop repeats its body a specified number of times.

Syntax:

```hl
loop for <count>
    ...
endloop
```

Example:

```hl
loop for 5
    text output "Hello!"
endloop
```

A variable can also be used for the number of repetitions:

```hl
define var count: int = 3

loop for count
    text output "Running"
endloop
```

---

# 12. While Loops

A `while` loop continues while its condition evaluates to true.

Syntax:

```hl
loop while <condition>
    ...
endloop
```

Example:

```hl
define var running: bool = true

loop while running
    text output "Running"
    # Change running to false when appropriate
endloop
```

Conditions can be boolean literals or boolean variables.

---

# 13. Break

`break` immediately exits the current loop.

Example:

```hl
loop for 10
    text output "Looping"
    break
endloop
```

Only one iteration reaches the loop body before `break` exits it.

---

# 14. Continue

`continue` skips the rest of the current loop iteration and continues with the next iteration.

Example:

```hl
loop for 5
    continue
    text output "This is skipped"
endloop
```

---

# 15. Lists

YubaLANG provides commands for manipulating lists.

## Append

```hl
list append <list> <value>
```

Example:

```hl
define var numbers: list = [1, 2]

list append numbers 3
```

The list is now:

```text
[1, 2, 3]
```

Strings can also be appended:

```hl
list append numbers "hello"
```

---

## Get an Item

Use:

```hl
list get <list> <index> <destination>
```

Example:

```hl
define var numbers: list = [10, 20, 30]
define var result: int = 0

list get numbers 1 result

text output result
```

The index starts at `0`, so the result is:

```text
20
```

---

## List Length

Use:

```hl
list len <list> <destination>
```

Example:

```hl
define var numbers: list = [10, 20, 30]
define var length: int = 0

list len numbers length

text output length
```

Output:

```text
3
```

---

# 16. Waiting

The `wait` command pauses execution for a number of seconds.

```hl
wait 1
```

A variable can also be used:

```hl
define var seconds: float = 2.5

wait seconds
```

# 17. Complete Example

The following program demonstrates variables, arithmetic, comparisons, conditionals, functions, and lists:

```hl
# YubaLANG example program

define var name: string = "YubaLANG"
define var version: float = 1.0
define var numbers: list = [10, 20, 30]

text output "Welcome to YubaLANG!"
text output name
text output version

arith sum numbers

define var biggest: int = 0
list get numbers 2 biggest

text output biggest

define var large: bool = false
compare biggest > 20 large

if large
    text output "The number is large!"
else
    text output "The number is small!"
endif

func define goodbye
    text output "Thanks for using YubaLANG!"
endfunc

func call goodbye
```

# 18. Error Handling

YubaLANG reports invalid commands, syntax, types, undefined variables, invalid
list operations, and other runtime problems with the source file, line, and
column. The relevant line is shown with a caret; when a likely correction is
known, the interpreter suggests it. For example:

```text
program.hl:1:13: error: Variable 'coutn' is not defined.
  line 1: text output coutn
                        ^^^^^
  hint: Did you mean 'count'?
```

Errors in functions and control-flow blocks point to the original source
location. Ordinary source errors do not show internal Python stack traces.
Invalid command syntax also includes the command's expected usage.
